<h2 align="center">Network Medicine Extension</h2>

<p align="center">This extension enables biomedical researchers to curate, annotate, and synchronize literature-derived findings.</p>

## Overview

This Chrome extension is developed by OpenProphetDB Research Group, an open research group dedicated to unlocking the potential of existing drugs to treat rare and complex diseases. The extension enables biomedical researchers to curate, annotate, and synchronize literature-derived findings into a Network Medicine Platform (https://drugs.3steps.cn).

Findings can be manually curated or machine-annotated from scientific literature and related data sources. This extension is intended for internal use only by researchers affiliated with the OpenProphetDB project, and is not designed for general public distribution.

## Installation

Access the [Network Medicine Extension](https://chromewebstore.google.com/detail/network-medicine-extensio/eamandgbalpjppofkhbefbbhckkkengp?authuser=0&hl=en) page on the Chrome Web Store.

Click "Add to Chrome" to install the extension.
